# Production AIO

Church AV control software built for operators, not accountants.

**Production AIO** controls PTZ cameras, ATEM video switchers, and audio from a single workspace — on macOS and Windows.

Current stable features include PTZ camera control over VISCA-over-IP (joystick, presets, zoom), ATEM program/preview switching, audio mixer control, multi-site project management, remote operation through a relay bridge so a volunteer can run a service from anywhere, and a demo mode so you can try everything without hardware connected.

We're a small team that actually runs AV at churches. Production AIO is a paid subscription, and every plan starts with a free trial — the full app, every feature unlocked, no credit card to begin and cancel anytime. We also do remote operator services and hardware installation: we show up when it counts.
